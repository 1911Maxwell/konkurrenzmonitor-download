# Konkurrenzmonitor

Der Konkurrenzmonitor liest die aktuellen Inseratzahlen von willhaben, ImmoScout24, immowelt, derStandard und immounited.com für Österreich und alle Bundesländer und stellt sie nebeneinander.

## Herunterladen

**[➜ Konkurrenzmonitor.zip herunterladen](https://github.com/1911Maxwell/konkurrenzmonitor-download/releases/latest/download/Konkurrenzmonitor.zip)**

Ein GitHub-Konto ist nicht nötig. Alle bisherigen Versionen stehen unter [Releases](https://github.com/1911Maxwell/konkurrenzmonitor-download/releases) bereit.

## Einrichten (einmalig)

1. Die ZIP-Datei herunterladen, mit Rechtsklick **„Alle extrahieren …“** wählen und entpacken, zum Beispiel auf den Desktop.
2. Im entpackten Ordner „Konkurrenzmonitor“ doppelt auf **„Einrichten“** klicken. Ein schwarzes Fenster zeigt kurz den Fortschritt und schließt sich dann von selbst.
   > Erscheint die Meldung *„Der Computer wurde durch Windows geschützt“*: **Weitere Informationen** und dann **Trotzdem ausführen** wählen.
3. Fertig. Auf dem Desktop liegt jetzt das Symbol **„Konkurrenzmonitor“**. ZIP-Datei und entpackter Ordner können danach gelöscht werden.

Wie die Zahlen abgerufen werden und was die Werte bedeuten, steht in der **[Anleitung (PDF)](ANLEITUNG.pdf)**.

## Aktualisieren

Ab Version 1.1.0 meldet der Konkurrenzmonitor neue Versionen beim Start selbst: Oben erscheint ein Hinweis mit dem Knopf **„Jetzt aktualisieren“**. Ein Klick genügt, das Programm lädt die neue Version, richtet sie ein und startet neu. Bisherige Abfragen und der Verlauf bleiben erhalten.

Ältere Versionen werden einmalig von Hand aktualisiert: ZIP-Datei über den Link oben herunterladen, entpacken und wieder auf **„Einrichten“** klicken. Die alte Version wird dabei ersetzt, der Verlauf bleibt erhalten.
